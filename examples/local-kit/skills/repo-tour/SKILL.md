# Repo tour

1. Read the top-level README, if there is one, and list the top-level files and directories.
2. Find the build and test commands (package manifests, Makefile, CI config).
3. Report back in at most ten bullet points:
   - what the project is, in one sentence
   - the main directories and what each holds
   - how to build it and how to run its tests
   - one good first file to read
